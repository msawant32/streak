# Streak

Track the things you want to do regularly, mark them done each day, keep your streaks, and get reminded when something is still not done. One codebase runs as a web app and as an Android app.

## Run it on your computer

You need [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
npm start
```

This opens **http://localhost:5173** in your browser. Changes to the code show up immediately.

| Command | What it does |
|---|---|
| `npm start` | Starts the app and opens the browser |
| `npm test` | Runs the unit tests (streak rules, reminders, storage, backup) |
| `npm run build` | Type-checks and builds the production web app into `dist/` |
| `npm run preview` | Serves the production build at http://localhost:4173 |
| `npm run android:sync` | Builds the web app and copies it into the Android project |
| `npm run android:open` | Opens the Android project in Android Studio |

## What it does

- **Today**: tap an activity's circle to mark it done. Activities with a target (for example 10 pages) also have a +1 button for partial progress. Undo appears for 5 seconds, and you can mark yesterday if you forgot.
- **Add activity**: name and reminder time. "Add notes" under the name opens a notes box. Schedule (every day, certain weekdays, times a week), second reminder and start date are under "More options".
- **Activity page**: current streak, longest streak, 30-day completion and the month calendar on one screen. Reminder and Today's note are rows that open a small dialog. Edit is in the header; Pause and Delete are on the edit screen.
- **Celebration**: marking something done sets off a brief burst where you tapped. Finishing everything for the day, or reaching 7, 30, 100 or 365 days, also shows a short message that fades by itself. It is plain CSS, with no library.
- **No scrolling**: every screen fits a 360×740 phone. Today and Progress scroll only when the list of activities is long.
- **Pause streak for a day**: appears on an activity only when its last scheduled day was missed, or after 9 PM when today is still not done. It excuses that one day so the streak carries on. Limited to 2 per activity per calendar month, and not shown anywhere else.
- **Progress**: done today, streaks running, best streak, and every activity with its streak.
- **Two reminders a day**, 8:00 AM and 8:00 PM by default, each with its own on/off switch. Defaults for new activities are in Settings. A reminder is sent only while the activity is still not done.
- **Automatic backup every 2 days**, replacing the previous one. On Android it goes to `Documents/Streak/streak-backup.json` (visible in the Files app); Settings shows the time and location of the last one. "Back up now" and "Import" are in Settings.
- **Erase all data** asks twice. A copy is kept for 2 days at `Documents/Streak/streak-erased.json` and can be restored from Settings or from the welcome screen; after 2 days it is deleted. Erasing also removes the automatic backup.
- **Hide names**: the eye button at the top of every screen shows only the first letter of each activity name ("R••••"), including in notifications. Tap it again to show names.
- **Previous best**: the activity page shows the longest streak that has ended, once there is one.
- **Private by design**: no account, no server, no tracking. Data stays on the device.

## Design rules

- **3 colours**: a soft neutral background, charcoal text, one muted sage accent. Greys are tints of the text colour; a muted red appears only on Delete and Erase.
- **3 text sizes**: title, body, small.
- Weeks start on Sunday.
- **3 tabs**: Today, Progress, Settings.
- **3 taps at most** for any action: mark done is 1 tap; add an activity is Add activity, type the name, Add activity; change a reminder is tap the activity, tap the time, pick it.

## Reminders: browser vs Android

- **Android app**: reminders are scheduled with the operating system and arrive when the app is closed, with "Mark done" and "Snooze 1 hour" buttons.
- **Browser**: reminders only arrive while Streak is open in a tab. This is a browser limitation.

## How the code is organised

```
src/
  domain/     Pure logic, no UI: dates, streak rules, reminder planning (unit tested)
  data/       Storage: IndexedDB (Dexie), repository, backup validation (Zod)
  platform/   Device features with browser and Android implementations: notifications, haptics, back button
  app/        Live data provider shared by every screen
  components/ Shared UI: buttons, dialog, toast, month calendar, bottom navigation
  features/   Screens: Today, Progress, Activity form and detail, Settings, Onboarding
android/      Android Studio project generated by Capacitor
.github/     Cloud build recipes: Android app and web preview
docs/         Android build guide, Play Store checklist, privacy policy template
```

Screens only talk to `data/repo.ts`, so storage can later be swapped for cloud sync without rewriting them.
